# NastyTavern UI locales

NastyTavern follows the language selected in SillyTavern. English is the fallback locale and `fr-fr` is included.

To add a translation, copy `en.json`, rename it to the locale code used by SillyTavern (for example `de-de.json`), translate only the values, and keep every key unchanged.

Missing entries automatically fall back to the original English string.
